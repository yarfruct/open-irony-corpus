# OpenIronyCorpus

This repository contains OpenIronyCorpus, a sentence-level irony dataset for Russian.

OpenIronyCorpus is a derivative of [OpenCorpora](http://opencorpora.org/), an open corpus of Russian texts.


## Content

There are two sets of sentences annotated by the presence of the irony:

* `dataset-a.csv` was annotated by volunteers;
* `dataset-b.csv` was annotated by the expert in linguistic.
